# cadnano reference files

| file | design | source |
|---|---|---|
| `Rothemund-rect.json` | Rothemund rectangle (24 helices × 288 bp) | [OpenWetware caDNAno file repository](https://openwetware.org/wiki/Biomod/2011/Harvard/HarvarDNAnos:caDNAnoFiles) |
| `Rothemund-tallrect.json` | Rothemund tall rectangle (32 helices × 224 bp) | same |

Original designs: P. W. K. Rothemund, "Folding DNA to create nanoscale shapes and patterns", *Nature* 440, 297–302 (2006).
The OpenWetware wiki content is available under GNU FDL or CC BY-SA unless otherwise noted.
The files carry no scaffold sequence; the reference scripts assign M13mp18 (p7249).
